# Reference archives

These are exact copies of the archives supplied by the project owner in the source conversation. They are retained as regression fixtures so the same packages do not need to be uploaded again.

- Do not modify or re-compress the originals.
- SHA-256 and byte sizes are recorded in `manifest.json`.
- The installer test suite uses synthetic fixtures; `reports/reference-package-audit.json` records the analysis of these real packages.
- These are private working references, not a public redistribution bundle.
